# Kerr County flood help — resource finder

A free, bilingual (English / Spanish) directory of flood-recovery resources
for Kerr County, Texas.

**Live site:** https://iechambless.github.io/kerrkind-flood-help/

## Authorship

Designed and built by **Elizabeth Chambless**, Lone Star AI, for Light on the
Hill at Mount Wesley (Kerr United Methodist Church), beginning August 2026.

Scope of the work: the bilingual resource directory, the Kerr Together brand
system, the printed resource guide packs, the case-manager packet, the
internal resource trackers, the Unmet Needs program framework and board
materials, and the automated build-and-test pipeline behind the site.

Every commit in this repository is authored and timestamped by Elizabeth
Chambless. That history is the record of authorship.
